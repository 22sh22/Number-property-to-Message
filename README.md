# Display specific Number Properties to Configured Messages!
- SIMPLE number-based stage description plugin
- The property display changes only affect active tabs in view.
- Supports EN/KO (file separated)
- Developed by 22sh22 with assistance from Claude AI
## Known Issue
- When editing a property's key value or adding a property with a configured name, the message won't appear immediately.
  Close and reopen the note to see the changes take effect.
